# 🤖 AI 모션 챌린지 | AI MOTION CHALLENGE

초등학교 AI 체험센터용 **오프라인 실시간 몸동작 게임**입니다. 학생 1명이 카메라 앞에서 움직이면 화면에 거울처럼 비친 실제 모습 위로 AI가 관절을 추적하고, 게임 판정과 점수를 실제 좌표로 계산합니다.

- **인터넷이 완전히 끊긴 학교 PC에서 실행됩니다.** 외부 API·CDN·클라우드·로그인·광고·통계 수집·음원·외부 영상 없음
- 세로형 부스(9:16)를 우선으로 설계했고, 가로(16:9)와 일반 PC 창도 지원합니다
- 학생 영상·사진·얼굴·이름은 저장하지 않습니다

## 게임 4종
| 게임 | 하는 일 | 판정 방법 |
|---|---|---|
| 🧍 **포즈 마스터** | 목표 자세 10종 중 랜덤 5라운드, 1초 유지 | 관절 각도·손목 높이·몸 기울기 유사도 + 시간 창 평활 + 유지 시간. PERFECT/GREAT/GOOD |
| 🔴 **레이저 탈출** | 다가오는 레이저 벽을 제자리에서 몸을 기울여 피하기. 목숨 3개, 3단계 속도 | 레이저가 닿는 순간 ±0.15초 동안 머리·가슴의 화면 좌표가 레이저 영역 안인지 확인 |
| 🏯 **백제 보물 탐험대** | 3개 구역 × (자세 미션 → 보물 3개) + 도감 | 손 위치가 보물 원 안에 0.7초 머무르면 획득 |
| 🚀 **우주 수호대** | 두 손이 방어막. 운석 막기 60초 + 보스(만세 방어막) | 운석 원과 손 방어막 원의 실제 겹침 |

공통 규칙:
- **인식이 끊기면(사람 없음, 2명, 화면 밖, 프레임 멈춤) 게임 시계가 멈추고 "잠시 멈춤"을 안내합니다.** 이때는 감점이나 실패로 처리하지 않습니다.
- 점프·뛰기·눕기·깊게 숙이기·이동은 요구하지 않습니다.
- **🪑 앉아서 하기:** 팔 중심 판정으로 바뀌고, 기울이기·허리 자세는 나오지 않습니다.
- **⌨ 대체 조작:** 터치·마우스·방향키로 레이저·보물·우주 게임을 할 수 있습니다.

## 실행
1. 웹캠을 연결합니다. 부스 상단 카메라가 연결되지 않으면 일반 USB 웹캠을 꽂습니다.
2. **`START_GAME.bat` 더블클릭** → 이 PC 전용 서버(`http://127.0.0.1:8770`)가 켜지고 전체 화면으로 열립니다.
   - 키오스크 모드: `scripts\START_KIOSK.bat`
3. 처음 한 번 카메라 권한을 "허용"합니다.
4. 끝낼 때는 오른쪽 위 **⏻ 종료 → 프로그램 종료**를 누릅니다. 창과 서버가 함께 꺼집니다.

설치·오프라인 준비: [INSTALL_OFFLINE.md](INSTALL_OFFLINE.md) · 교사용 안내: [TEACHER_GUIDE.md](TEACHER_GUIDE.md) · 테스트 결과: [TEST_REPORT.md](TEST_REPORT.md) · 자산 라이선스: [ASSET_LICENSES.md](ASSET_LICENSES.md)

## 기술 구성과 선택 이유
| 영역 | 구현 |
|---|---|
| 화면 | 빌드 없는 ES 모듈 JavaScript + Canvas 2D |
| 동작 인식 | MediaPipe Tasks Vision **0.10.35** Pose Landmarker(VIDEO 모드), 모델·WASM 로컬 |
| 서버 | Windows 기본 PowerShell 5.1 로 만든 정적 파일 서버, **127.0.0.1에만 바인딩** |
| 폰트 | Pretendard(OFL), 로컬 포함 |
| 효과음 | Web Audio 합성(음원 파일 없음) |

- **React/TypeScript/Vite 대신 빌드 없는 JavaScript를 쓴 이유:** 학교 PC에 Node.js나 빌드 도구를 설치하지 않고, 폴더 복사만으로 실행되게 하기 위해서입니다. 모듈은 `PoseEngine`(pose/engine.js), `Calibration`(pose/calibration.js), 자세 인식(pose/poses.js), 충돌 판정(각 게임의 `laserCollides`·`handOn`·`circlesHit`), 게임 관리(main.js), 설정(core/settings.js)으로 나누었고, 게임 로직은 화면과 분리해 단위 테스트합니다.
- **MediaPipe를 0.10.35로 고정한 이유:** 1.x 버전 번들에는 `odml.pa.googleapis.com`으로 사용 통계를 보내는 코드가 들어 있습니다. 외부 전송 금지 조건 때문에 외부 주소가 없는 0.10.35를 씁니다.

## 좌표 규칙(좌우 반전)
- AI 판정(자세의 왼쪽/오른쪽)은 **카메라 원본 좌표**와 **학생 본인 기준 왼쪽/오른쪽**을 씁니다.
- 거울 표시는 **화면에 그릴 때만** 적용합니다.
- 게임 물체(레이저·보물·운석)는 **화면 좌표**에 놓습니다. 판정할 때도 같은 화면 좌표로 바꾼 손·머리 위치를 쓰므로, 보이는 위치와 판정 위치가 항상 일치합니다(`pose/body.js`).
- 키 차이는 몸통 길이 T(어깨 중심~골반 중심)로 정규화합니다. 앉아서 골반이 안 보이면 어깨 폭으로 추정합니다.
